# Autonomous Execution Directive

1. **NEVER Ask Conversational Permission:**
   - Do not ask "Shall I start?", "Would you like me to do X?", "Should we proceed?", or wait for user consent on planned steps.
   - Proactively execute, edit files, run necessary commands, and verify results autonomously.

2. **Full Initiative on Next Steps:**
   - Whenever an implementation phase or step is clear, execute it directly and report the finished results.
   - Stop only when a critical external decision (e.g., irreversible production database drop) genuinely requires user input.
